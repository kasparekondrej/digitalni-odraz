# Google Ads agent

Druhý specializovaný agent pod odrazem, návrh z 5. 11. 2026. Podklady pro rozhodnutí 6. 11. jsou v Claude Docu „Podklady: první agent na Google Ads“.

Stav: návrh. Nic neběží, dokud Ondřej nerozhodne o první úloze, pilotních účtech a zdroji dat.

První úloha (návrh): týdenní kontrola hledaných výrazů a vylučujících slov, viz [SKILL.md](SKILL.md). Vychází ze [standardu reportu](../kontrolor-reportu/standard.md) (řádek Google Ads Search) a pracuje stejně jako [Kontrolor reportů](../kontrolor-reportu/README.md): práci si najde sám, výsledek zapíše do Claude Docu, návrh pro specialistu odejde až po Ondřejově „pošli“.

## Otevřené otázky pro Ondřeje

- Pilotní specialista a účty.
- Zdroj dat: exporty na Drive, nebo connector jen pro čtení (Google Ads connector v claude.ai není).
- Cílové hodnoty metrik pilotu.
