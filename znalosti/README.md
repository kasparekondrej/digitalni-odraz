# Znalosti z projektových vláken

Každé vlákno v projektu „Me“, které dojde k závěru, sem zapíše necitlivé shrnutí: co Ondřej rozhodl, z čeho to vychází a co z toho plyne pro odraz. Hlavní agent ([odraz-hlavni-agent](../skills/odraz-hlavni-agent/SKILL.md)) tyhle soubory čte, když řeší podobné téma.

Pravidla:
- Jeden soubor na téma, název `tema-v-kebab-case.md`. Když se téma vrátí, soubor se aktualizuje, nevzniká nový.
- Nahoře datum poslední změny a stav (návrh, schváleno, běží, ukončeno).
- Bez sazeb, odměn a hodnocení konkrétních lidí, viz [citlivé informace](../pravidla/citlive-informace.md). Detaily zůstávají v Claude Docs a v projektových souborech, sem patří odkaz.
- Čísla jen s uvedeným zdrojem. Co chybí, je [doplnit].
